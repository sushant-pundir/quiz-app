# Quiz Application

A browser-based multiple-choice quiz application built
with HTML, CSS and JavaScript.

## Features

- Multiple-choice questions
- Interactive answer selection
- Automatic score calculation
- Final score display
- Simple browser-based interface

## Technologies

- HTML5
- CSS3
- JavaScript

## Installation

Clone the repository:

    git clone https://github.com/sushant-pundir/quiz-app.git

Enter the folder:

    cd quiz-app

## Run

Start a local server:

    python3 -m http.server 5503

Open:

    http://localhost:5503
